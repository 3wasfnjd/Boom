# Approved BOOM loading artwork

`boom-chase-approved.webp` is the exact user-approved illustration, encoded
as lossless WebP. The decoded RGB pixels match the approved PNG at 941 × 1672.

Approved PNG SHA-256: `c39e86351cd87247be62bdfcc37ad10f181e001b14562887fa2e2377ea2c5334`.

The loading stylesheet masks the sample HUD baked into the bottom of the image.
HTML renders the real percentage, a slanted cyan-to-yellow rail, a glowing diamond
at the fill endpoint, and the same Arabic copy in that area. The composition is
contained at its original aspect ratio, with a blurred extension behind it for
other screen shapes. Startup progress remains tied to completed game assets.
