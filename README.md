# BOOM — ساحة الاستراحة

## فكرة المستودع
لعبة قتال ومطاردات بالسيارات من عبودين قيمز، في ساحة ثلاثية الأبعاد مستوحاة من عالم موتري، تجمع القيادة والرماية والقتال بين اللاعبين.

## الخدمات والمزايا
- سيارات هافال H9 والشاص والددسن بأسلحة مختلفة.
- غرف لعب جماعي حتى ستة لاعبين، مع صحة للسيارات وعداد قتل وعودة بعد التحطم.
- أهداف تدريب وصناديق متفجرة يمكن قذفها خلف السيارة.
- تضاريس واستراحة وكثبان وطقس ودورة نهار وليل.
- قيادة وإطلاق متزامنان باللمس، ودعم لوحة المفاتيح ويد التحكم.
